# Contributing

This tree is a local extract. Access does not mean publish.

1. Read `docs/OFFBOARD.md` and `docs/REMOTE-POLICY.md`.
2. Do not add factory keys, operator inboxes, or Access identity.
3. Run `make verify`.
4. Keep Go the bucket reference. Update `schemas/parity-fixture.json` only
   when all three languages change together.
5. Do not add a public remote.
